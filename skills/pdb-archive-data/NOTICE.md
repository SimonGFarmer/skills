Skill instructions, helper code and tests: copyright 2026 Simon G Farmer, licensed under [MIT](LICENSE). This software license does not relicense upstream data or software. No archive data, images, third-party code or credentials are bundled.

The helper reads public official RCSB PDB services and retrieves deposited wwPDB coordinate files. According to [RCSB usage policies](https://www.rcsb.org/pages/policies), PDB archive data files are available under CC0 1.0; RCSB programmatic API data use the same terms except annotations originating from integrated external resources, whose provider restrictions still apply. Retain raw metadata and check the terms of any external annotation used in derived work.

Cite the PDB accession and original structure publication where available, and acknowledge the RCSB PDB and wwPDB following their [citation policies](https://www.rcsb.org/pages/policies). The Protein Data Bank reference is Berman et al. (2000), Nucleic Acids Research 28:235-242, https://doi.org/10.1093/nar/28.1.235. These organizations do not endorse this skill.

Gemmi is an optional analysis dependency, not bundled or required by this retrieval helper. Consult its own license and record the installed version if using it to parse coordinates.
