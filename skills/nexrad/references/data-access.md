# Sources and selection

- [NOAA NCEI NEXRAD](https://www.ncei.noaa.gov/products/radar/next-generation-weather-radar): Level II base moments include reflectivity, radial velocity, spectrum width and dual-polarization variables. Level III derived products are a different format/workflow; these helpers do not decode them.
- [AWS NEXRAD registry](https://registry.opendata.aws/noaa-nexrad/) identifies `unidata-nexrad-level2` for Archive II and a separate real-time chunks bucket. The older `noaa-nexrad-level2` bucket is deprecated. Anonymous archive access needs no AWS credentials.
- [Archive browser](https://unidata-nexrad-level2.s3.amazonaws.com/index.html) and [S3 ListObjectsV2 contract](https://docs.aws.amazon.com/AmazonS3/latest/API/API_ListObjectsV2.html): prefix `YYYY/MM/DD/KXXX/`; follow continuation tokens, exclude metadata (`_MDM`) and deduplicate. Listing failures must propagate, never become empty success.
- [NWS radar stations](https://api.weather.gov/radar/stations) and [API guidance](https://www.weather.gov/documentation/services-web-api): GeoJSON coordinates are longitude, latitude. Helpers send an identifying User-Agent. Cache results in an application; station metadata elevation is not automatically radar antenna altitude.

Selection uses object filename time, start inclusive and end exclusive. Publication `LastModified`, filename time, individual ray times and final volume time are different. If a request depends on scan completion or overlap, discover a wider interval and filter decoded ray times; do not treat key time as completion. UTC day boundaries are handled by the helper. Recent requests should use the current UTC time and a bounded lookback, then choose a listed file deliberately. Archive ingestion may lag and some stations/intervals have gaps. Downloaded volumes are not cropped by distance or reflectivity.

Downloads default to the earliest one file and 50 MB total. Listed sizes are checked before and during transfer; partial files are removed on failure. Existing files are never overwritten. No automatic retries or unbounded station-wide downloads. JSON `observations` includes key, URL, size, key time and publication time; downloaded rows add absolute local paths. Preserve these alongside derived results. Network timeout is 60 seconds per request; cancel long operations as needed. Downloads are not cryptographically verified by these helpers.
