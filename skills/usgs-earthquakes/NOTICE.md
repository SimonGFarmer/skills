# Data attribution

Credit earthquake catalog and feed data to the U.S. Geological Survey, ANSS Comprehensive Earthquake Catalog (ComCat), and the contributing seismic networks identified in each record. Retain retrieval date, request URL, event ID, update time, network and magnitude/location source. For a downloaded product retain its source, type, code, update time and content URL.

[USGS copyright and credit guidance](https://www.usgs.gov/information-policies-and-instructions/copyrights-and-credits) distinguishes USGS-produced information in the U.S. public domain from third-party material. Inspect attribution and terms for each contributed product before redistributing it. Access through USGS does not establish that every contributed image or file has the same rights. Data terms do not assign a license to this skill's authored helper code or instructions.
