# Calibrated COG windows and quality

Discovery metadata and rendered PNG previews are separate from numerical band data. For a numerical workflow install `pystac-client`, `planetary-computer`, `rasterio` and NumPy in an isolated Python environment. Check supported versions for that environment. Use official item metadata and read a bounded raster window through COG range requests; do not download a whole scene for a small region. Inspect each asset's CRS, transform, native resolution, dtype, nodata and scaling before combining arrays. HTTP transfer and GDAL resource bounds require their own validation.

Raw Planetary Computer Azure assets require transient SAS signing. Keep pristine unsigned items and call `planetary_computer.sign` shortly before access. Container tokens are cached by the official SDK and refreshed near expiry; already-signed URLs are returned unchanged, so re-signing an expired URL does not refresh it. Obtain fresh unsigned metadata for a retry. Do not save signed URLs, tokens or subscription keys in reports, fixtures or source. [Official signing implementation](https://github.com/microsoft/planetary-computer-sdk-for-python/blob/main/planetary_computer/sas.py).

Landsat Collection 2 surface reflectance is dimensionless: `DN * 0.0000275 - 0.2`. Apply nodata and chosen sensor-specific QA_PIXEL/QA_RADSAT policies before analysis. Surface temperature has different scaling and units; do not apply optical factors to it. QA layouts differ between Landsat generations. Scene cloud fraction and rendered alpha do not substitute for pixel QA. [USGS scaling](https://www.usgs.gov/faqs/how-do-i-use-a-scale-factor-landsat-level-2-science-products), [QA definitions](https://www.usgs.gov/landsat-missions/landsat-collection-2-quality-assessment-bands).

Sentinel-2 L2A reflectance is `(DN + BOA_ADD_OFFSET) / QUANTIFICATION_VALUE`; read product/asset metadata to establish the applicable processing baseline and representation. DN zero is nodata. Reprocessed older acquisitions can have newer baselines; acquisition date alone cannot select an offset. Do not apply an offset twice to harmonized data. RGB uses B04/B03/B02 at 10 m, while SCL is 20 m. Resample categorical masks with nearest sampling, state the common analysis grid, and document the SCL classes excluded. [Copernicus product definitions](https://sentiwiki.copernicus.eu/web/s2-products).

Report sample counts after masking and preserve missing values. Normalized indices require calibrated bands and a nonzero denominator. Same-grid rendering does not eliminate geolocation error, viewing/illumination effects, atmosphere, processing differences or seasonal effects. A visual difference is a discovery aid; measuring change requires a justified scientific comparison and uncertainty treatment.
