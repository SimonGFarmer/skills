# Authorship and data attribution

Skill instructions and helper code: copyright 2026 Simon G Farmer, licensed under [MIT](LICENSE). This code license does not license survey data, imagery or upstream software.

Measurements and spectrum files are supplied by the Sloan Digital Sky Survey. The helpers query public official services; no survey data, imagery or third-party software is bundled. SDSS describes its public data releases as public domain in its [image permissions and data policy](https://www.sdss.org/science/image-gallery/#image-permissions). Gallery images have separate attribution requirements; this package contains none.

For research using SDSS, cite the appropriate data release and pipeline papers and follow the [SDSS acknowledgement guidance](https://www.sdss.org/collaboration/citing-sdss/). Retain the actual catalog release, archive release, instrument, reduction version, observation identifiers and retrieval URL in derived work. SDSS does not endorse this skill.
