Gaia measurements belong to the ESA Gaia mission and the Gaia Data Processing and Analysis Consortium (DPAC). ESA's [Gaia data license page](https://www.cosmos.esa.int/web/gaia-users/license) identifies CC BY-NC 3.0 IGO for the distributed data. Check those data terms for the intended use. Preserve release, source identifiers, query, acquisition time, units and omission status when distributing results.

When publishing analysis, follow the release-specific [ESA credits and acknowledgements](https://www.cosmos.esa.int/web/gaia-users/credits), including the Gaia mission, DPAC and the appropriate release papers. The organizations do not endorse this skill. The software MIT license and the data license serve different purposes.
